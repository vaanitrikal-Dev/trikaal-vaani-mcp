# Trikaal Vaani Jyotish — MCP Server

**Granth ka Gyaan · Rohiit ki Parakh · AI ki Shakti** — Rooted in Granth · Powered by Swiss Ephemeris.

Official [Model Context Protocol](https://modelcontextprotocol.io) server of [Trikaal Vaani](https://trikalvaani.com), a Vedic astrology (Jyotish) platform by Rohiit Gupta, Chief Vedic Architect (New Delhi, India). It lets AI assistants compute real Vedic astrology results instead of guessing.

- **Server URL (Streamable HTTP):** `https://mcp.trikalvaani.com/mcp`
- **Authentication:** none — public, free, read-only. No birth data is stored.
- **MCP Registry:** `com.trikalvaani/jyotish`
- **Docs:** https://mcp.trikalvaani.com · **Privacy:** https://mcp.trikalvaani.com/privacy · **Terms:** https://mcp.trikalvaani.com/terms

This repository contains documentation and client configuration only. The server itself is hosted by Trikaal Vaani.

## Connect

**Claude:** Settings → Connectors → Add custom connector → paste `https://mcp.trikalvaani.com/mcp`.

**Gemini CLI:**
```bash
gemini extensions install https://github.com/vaanitrikal-Dev/trikaal-vaani-mcp
```

**Any MCP client (JSON config):**
```json
{ "mcpServers": { "trikaal-vaani-jyotish": { "url": "https://mcp.trikalvaani.com/mcp" } } }
```

## How it works

Planetary positions come from the Swiss Ephemeris with Lahiri Ayanamsha. Interpretation follows classical granths; readings are written from the texts, not generated by an AI model. Results are guidance, not medical, legal or financial advice. Full reports, remedies and personal consultation are available on [trikalvaani.com](https://trikalvaani.com).
